# Bradley French Portfolio

Static portfolio site (architecture, interiors and visualization). No build step.

- `index.html` – the whole site (markup, styles, script)
- `copy.js` – project descriptions
- `map.js`, `map2.js` – map geometry for the Map page
- `img/` – project images and thumbnail sheets
- `apple-touch-icon.png`, `icon-*.png`, `manifest.webmanifest` – home-screen icon and install settings

Open `index.html` in a browser, or serve the folder with any static host.

Project images are shown as work produced while at the credited firm.
